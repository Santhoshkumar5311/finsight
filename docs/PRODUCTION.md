# Deployment and release gates

The local instance is for one owner on loopback. Production scaffolding is supplied, but cloud deployment, provider certification and latency SLOs have not been validated locally.

1. Run `npm ci`, `npm run setup:imports`, `npm run release:check`, and the mobile typecheck. CI also builds both Docker images. Never put statements, local encryption keys or `.env` files into build contexts or git.
2. Provision private PostgreSQL with pgvector/pgcrypto, Redis with TLS, RabbitMQ with TLS, a private Presidio analyzer, Supabase Auth, and S3/KMS. `infra/security.tf` provides a security foundation within an existing VPC/ALB, including private encrypted RDS, WAF, KMS rotation and locked audit storage; it does not provision the complete hosting environment. Inspect a Terraform plan before applying it.
3. Use a separate migration identity to run `npm run db:migrate` with `DATABASE_URL` and the trusted CA in `DATABASE_SSL_CA`. Create distinct LOGIN identities with randomly generated secrets, granting `finsight_api` to the API login and `finsight_worker` to the worker login. Neither login may own tables, be superuser or bypass RLS. Never use the Supabase service-role key as a browser credential.
4. Copy `infra/production.env.example` to `.env.production` and fill the deployment settings. Supply database credentials through a secret manager. API and worker URLs must use their respective restricted roles. Supply the database CA file, independent random 32-byte HMAC keys, KMS key ARN, private service URLs, and provider credentials. Use workload IAM roles: API needs the audio policy; worker also needs the audit-export policy. No AWS static keys belong in images.
5. Configure Supabase OAuth, confirmation/recovery mail, redirect allowlists and TOTP. See [authentication](AUTHENTICATION.md). Compile native apps with primary and backup SPKI pins for your actual API domain; test rotation on physical devices.
6. Build/run on a trusted private host: `docker compose --env-file .env.production -f compose.production.yml up --build -d`. Caddy exposes web/API TLS 1.3 endpoints; DB, cache, queue, worker and API container ports are not published. Attach WAF at your actual ingress and enforce private routes/firewall rules. Caddy alone does not supply a WAF or private VPC. The API requires `/ready` dependencies to be healthy; worker exposes its internal health endpoint on 4001.
7. Run live two-user isolation, Plaid Link/history/webhook/replay/reconnect, MFA/recovery/logout, S3 owner-access, KMS rotation, immutable-audit export, backup/restore, queue outage/retry and upload resource-exhaustion tests. Confirm audit objects land with retention and that runtime roles cannot mutate audit rows. Configure alerts for export lag, dead letters, webhook failures and readiness failures.
8. Measure webhook-to-visible-dashboard and LLM response latency under load. The requested 2-second/1-second bounds are targets, not guarantees. Local Qwen3 is especially unlikely to meet a 1-second full-response target. Keep financial arithmetic deterministic and asynchronous AI work out of the webhook critical path.

The API and worker are separate processes. Redis shares Socket.io events, session revocation and user quotas across API replicas. PostgreSQL holds the durable webhook inbox; RabbitMQ wakes the worker, with dead-letter/replay handling. Audit rows are append-only for runtime roles and periodically copied to SSE-KMS S3 objects with Object Lock. Configure retention to your actual requirements; do not grant the writer governance-retention bypass or delete permissions.

ICICI is supported through reconciled statement import; the India Account Aggregator adapter is only a local mock and is rejected in production. No live ICICI banking integration is claimed. Offline audio can be recorded and stored locally, but automatic Whisper transcription requires the configured hosted service in live mode. Browser certificate pinning and Secure Enclave storage of arbitrary tokens are not available; native Keychain/Keystore and native pinning are separate platform controls.
